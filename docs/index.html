Not Simülatörleri

İki öğrenci için bac ve dönem ortalaması simülatörü: hangi derste kaç puan, genel ortalamayı ve mention'ı nasıl değiştirir? Notlar bu sitede durmaz; kilitli bir GitHub reposundan salt-okunur token ile okunur.

Kurulum — salt-okunur token

Token yalnız bu tarayıcıda saklanır; hiçbir sunucuya, URL'ye veya kayda yazılmaz.
Token nasıl oluşturulur?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: hesabınız. Repository access: Only select repositories → yalnız veri reposu.
  3. Permissions → Repository permissions → Contents: Read-only. Başka hiçbir yetki vermeyin.
  4. Expiration: 90 gün. Süre dolunca site "token geçersiz" der; aynı adımlarla yenisini üretin.
  5. Token'ı yukarıdaki alana yapıştırın ve "Bağlan ve test et" deyin.

Gizlilik

  • Bu site herkese açık bir GitHub Pages sitesidir; içinde hiçbir gerçek not, ad veya okul bilgisi yoktur. Token yokken uydurma örnek veri gösterir.
  • Gerçek notlar ayrı, kilitli bir repoda durur. Site onları yalnız okur; kodda yazma çağrısı yoktur ve bu CI'da denetlenir.
  • Token tarayıcınızın yerel deposunda kalır. Aynı GitHub hesabının diğer Pages siteleri aynı origin'i paylaştığı için token'a erişebilir; bu yüzden token salt-okunur, tek repoya kısıtlı ve 90 günlüktür.
  • Ekrandaki "Özel" senaryo ve geçici notlar sekme kapanınca silinir; hiçbir yere yazılmaz.
